# Required External Resources

For completion of current user acceptance:

- One real phone (preferably Android Chrome first; iPhone/Safari as a separate result).
- Permission to use its microphone for the temporary HTTPS page.
- Network access from PC to Cloudflare Quick Tunnel and from phone to the generated URL.

Only for later controller-approved stages:

- Cloud LLM API key/provider choice.
- Real wheelchair, ESP32/STM32 interface, exact CAN/UART schema, error/ACK semantics.
- ROS2 Topic/Service definitions if ROS2 is selected.
- Independent physical E-stop requirements and hardware safety review.
- Hosting account/domain if a persistent HTTPS deployment is selected.
