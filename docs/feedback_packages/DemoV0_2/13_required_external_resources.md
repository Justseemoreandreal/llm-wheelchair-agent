# 后续需要的外部资源

完成 V0.2 软件交付不需要用户提供云端 LLM Key、硬件协议或提交录音。**要完成真实设备验收**，需要用户：

1. 用目标华为/HarmonyOS 手机扫描运行中的临时二维码，说明系统/浏览器版本，允许麦克风，现场说“停下”。
2. 在 Edge/手机本地选择其三段私人录音，记录 partial/final、RMS、WebSocket/model 状态和错误码；音频无需上传 Git。
3. 如有失败，提供页面诊断截图、导出的验收 JSON、复现步骤以及是否使用 HTTPS。

未来若总控批准其他阶段，可能另需：稳定 HTTPS 账号/域名；云端 LLM API Key；底盘团队正式 ESP32/STM32/CAN/UART 或 ROS2 接口、真实设备、独立物理急停与受控场地。此处只是资源清单，不是开启下一阶段的请求。
